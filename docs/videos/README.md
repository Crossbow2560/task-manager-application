# Sprint outcome videos

- [Sprint 1: one minute](Sprint_1_One_Minute.webm): genuine API operations from historical source `ea72d56`, restored in a separate checkout. The viewer is an independent recording aid; that source did not have a connected web UI. It is explicitly labelled a reconstruction captured on 17 November 2026.
- [Sprint 2: two minutes](Sprint_2_Two_Minutes.webm): the final connected browser application. Registration/login, projects, task creation/assignment, lifecycle changes, comments, search/filter, dashboard and reminders are demonstrated against real PostgreSQL.

The on-screen captions and adjacent `*-capture.json` files distinguish the source revision from the recording date. Files are WebM/VP9 at 1280 x 900, 25 frames/second, with explanatory captions and no audio. Final durations were verified from decoded frame counts: 60 and 120 seconds.

See [submission timeline](../Submission_Timeline.md) for chronology and [implementation/validation notes](../validation/RUN_AND_VALIDATE.md) for reproduction. These videos were created retrospectively; they are not presented as recordings made on the original sprint dates.
